# ⚡ Quick Start - 5 Minute Setup

## 🎯 Fastest Way to Run GameArena

### Step 1: Open Android Studio (30 seconds)
```
1. Launch Android Studio
2. Click "Open"
3. Select: D:\AndriodStudioAPK
4. Click OK
```

### Step 2: Wait for Sync (5-10 minutes first time)
```
Look at bottom status bar:
"Gradle: Syncing..." → Wait until complete
```

### Step 3: Create Emulator (2 minutes)
```
1. Click 📱 Device Manager icon
2. Click "Create Device"
3. Select "Pixel 5" → Next
4. Select "API 34" (download if needed) → Next
5. Click Finish
6. Click ▶️ to start emulator
```

### Step 4: Run App (1 minute)
```
1. Click green ▶️ RUN button at top
2. Wait for build and install
3. App launches automatically!
```

## 🐛 If Something Goes Wrong

### Sync Failed?
```bash
File → Invalidate Caches → Restart
```

### Build Failed?
```bash
Build → Clean Project
Build → Rebuild Project
```

### App Crashes?
```bash
Check Logcat tab at bottom for errors
```

### Device Not Found?
```bash
Create new emulator (Step 3 above)
```

## 📱 Want to Run on Your Phone?

### Enable USB Debugging:
1. **Settings → About Phone**
2. **Tap Build Number 7 times**
3. **Settings → Developer Options**
4. **Enable USB Debugging**
5. **Connect USB cable**
6. **Select your phone in Android Studio**
7. **Click Run ▶️**
