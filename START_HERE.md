### 🔥 **Option B: Full App Run (10 minutes)**
**Test all CRUD operations with Firebase!**

#### Step 1: Enable Firestore (2 min)
1. Open [Firebase Console](https://console.firebase.google.com/)
2. Select **GameArena** project
3. Click **Firestore Database**
4. Click **Create Database** → **Test mode** → **Enable**

#### Step 2: Sync & Build (2 min)
1. Open **Android Studio**
2. Open project: `D:\AndriodStudioAPK`
3. Wait for Gradle sync
4. Click: **Build → Rebuild Project**

#### Step 3: Run & Test (5 min)
1. Click **Run** button (green triangle)
2. Login to the app
3. Click **☁️ Cloud icon** on Home screen (top-right, neon yellow)
4. Test all CRUD operations!
